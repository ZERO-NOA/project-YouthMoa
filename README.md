# 대학생·청년 지원 혜택 통합 조회 웹

## 1. 프로젝트 소개

공공 API를 활용하여 대학생과 청년을 위한 다양한 지원 혜택을 한곳에서 검색하고 확인할 수 있는 웹 서비스입니다.

지원금, 복지서비스, 교통, 할인, 교육 등 여러 분야의 정보를 통합하여 사용자가 자신에게 필요한 혜택을 쉽게 찾을 수 있도록 하는 것을 목표로 합니다.

## 2. 주요 기능

### 기본 기능
- 공공 API를 활용한 지원 혜택 정보 조회
- 키워드 기반 검색
- 카테고리별 혜택 조회
- 지원 혜택 상세 정보 확인
- 회원가입 및 로그인

### 확장 기능
- 관심 혜택 즐겨찾기
- 사용자 조건에 따른 맞춤형 검색
- 신청 마감일 및 일정 표시
- 추가 공공 API 연동

※ 확장 기능은 기본 기능 구현 완료 후 개발 상황에 따라 추가합니다.

## 3. 기술 스택

| 영역 | 기술 |
|---|---|
| Frontend | React, Vite |
| Styling | CSS 또는 Tailwind CSS |
| Backend | Python, FastAPI |
| Database | SQLite, SQLAlchemy |
| External API | 공공데이터포털 OpenAPI |
| Version Control | Git, GitHub |

## 4. 활용 API

- API명: 지자체 복지서비스 OpenAPI
- 제공처: 공공데이터포털
- 공식 문서: https://www.data.go.kr/data/15108347/openapi.do

실제 API 요청 방식, 응답 필드, 호출 제한 및 인증 조건은 공식 문서를 기준으로 확인합니다.

## 5. 프로젝트 폴더 구조

- `frontend/`: 사용자 화면 및 프론트엔드 기능
- `backend/`: API 연동, 검색, 인증 및 데이터베이스
- `docs/`: API 명세서, DB 설계, 팀원 역할 분담 문서

## 6. 개발 및 실행

프론트엔드와 백엔드는 각각 독립적으로 실행합니다.

- 프론트엔드: `frontend/README.md` 참고
- 백엔드: `backend/README.md` 참고

## 7. 팀 구성

총 4명으로 구성된 팀 프로젝트입니다.

- 이용희: 프론트엔드 및 메인 화면 / 배포
- 이주찬: 외부 API 연동 및 데이터 처리
- 김동영: 검색·필터 및 데이터베이스 / 통합
- 이동화: 웹 디자인 / 회원 기능·배포 / 테스트

## 8. 개발 목표

공공 API 연동, 검색, 카테고리별 조회 및 회원 기능을 갖춘 웹 서비스를 구현하고, 배포 환경에서 정상적으로 작동하는지 검증합니다.
