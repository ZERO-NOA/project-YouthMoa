# API 명세서

## 1. 외부 API 정보

- API명: 지자체 복지서비스 OpenAPI
- 제공처: 공공데이터포털
- 공식 문서: https://www.data.go.kr/data/15108347/openapi.do
- 데이터 형식: 공식 명세 확인 후 적용
- 인증 방식: 공식 명세 확인 후 적용

## 2. 내부 API 공통 규칙

- 기본 응답 형식: JSON
- HTTP 상태 코드를 사용하여 요청 성공 및 오류를 구분합니다.
- 외부 API 인증키는 백엔드에서만 사용합니다.
- 검색 조건이 없는 경우 전체 조회 또는 기본 목록을 반환하도록 설계합니다.

## 3. 혜택 API

### 혜택 목록 조회

- Method: `GET`
- Endpoint: `/api/benefits`

예상 검색 파라미터:

| Parameter | 설명 |
|---|---|
| `keyword` | 제목 또는 내용 검색어 |
| `category` | 혜택 카테고리 |
| `page` | 페이지 번호 |
| `size` | 페이지당 결과 수 |

### 혜택 상세 조회

- Method: `GET`
- Endpoint: `/api/benefits/{id}`

상세 정보 후보:
- 서비스명
- 서비스 설명
- 지원 대상
- 선정 기준
- 신청 방법
- 관련 기관
- 공식 안내 링크

실제 제공 항목에 따라 응답 필드를 확정합니다.

## 4. 회원 API

### 회원가입

- Method: `POST`
- Endpoint: `/api/auth/signup`

예상 입력:
- 이메일 또는 로그인 ID
- 비밀번호

### 로그인

- Method: `POST`
- Endpoint: `/api/auth/login`

인증 성공·실패 응답과 세션 또는 토큰 처리 방식은 팀에서 합의합니다.

## 5. 오류 처리

- `400`: 잘못된 요청
- `401`: 인증 필요 또는 인증 실패
- `404`: 대상 리소스 없음
- `422`: 입력값 검증 실패
- `500`: 서버 내부 오류
- `502` 또는 `503`: 외부 API 오류 또는 서비스 이용 불가

## 6. 변경 관리

API 경로, 필드명, 응답 구조를 변경할 경우 팀원들과 공유하고 이 문서를 함께 갱신합니다.
