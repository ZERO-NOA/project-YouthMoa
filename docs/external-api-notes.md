# 외부 API 연동 메모 — 한국사회보장정보원 지자체복지서비스

- 데이터포털: https://www.data.go.kr/data/15108347/openapi.do
- Base: `https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations`
- 목록 `/LcgvWelfarelist` · 상세 `/LcgvWelfaredetailed` · 응답 XML

## 확인 상태 (2026-10-24 실제 호출 2회 기준)

| 항목 | 상태 | 비고 |
|---|---|---|
| 목록/상세 호출, `servId`, 키워드(`searchWrd`) | ✅ 실측 | 전체 4,826건, '월세' 106건 |
| 목록·상세 응답 태그 | ✅ 실측 | 지역 `ctpvNm`/`sggNm`, 생애주기 `lifeNmArray`, 주제 `intrsThemaNmArray`, 담당부서 `bizChrDeptNm`, 신청 `aplyMtdNm` 등 |

| 일일 호출 한도 | 계정별 상이 | 활용신청 상세 화면에서 확인 |

## 데이터 특성
- 한 서비스가 여러 생애주기를 가집니다(`lifeNmArray`가 쉼표 목록). 그래서 필터 결과의 생애주기명에도 여러 값이 나옵니다.
- `lifeNmArray`/`intrsThemaNmArray`가 비어 있는 서비스가 있습니다(필터 결과에는 나오지 않음).
- **주제 태그가 한쪽으로 쏠려 있습니다.** `서민금융(130)`이 3,165건(약 65%)이고 `주거(040)` 55건, `보육(090)` 1건, `생활지원(030)` 8건입니다. 카테고리 탭을 주제 코드만으로 만들면 탭마다 결과 수 편차가 크고(청년 필터를 겹치면 주거 14건 수준), `금융` 탭은 사실상 전체와 비슷해집니다. → 키워드 검색(`월세` 106건)을 병행하는 것을 권장합니다.
- 가운뎃점 표기가 일정하지 않아(`임신 · 출산` / `임신·출산`) 코드에서 `임신·출산` 으로 통일합니다.

## 서비스키 주의
- Encoding/Decoding 키 어느 쪽을 `.env`에 넣어도 동작합니다(한 번 디코딩 후 단일 인코딩).
- 활용신청 직후 "등록되지 않은 서비스키"(코드 30)는 승인 후 수 분~1시간 지연일 수 있습니다.
- 키는 절대 커밋하지 않습니다.
