# 팀원 역할 분담

## 프로젝트 개요

- 프로젝트명: 대학생·청년 지원 혜택 통합 조회 웹
- 팀 규모: 4명
- 핵심 기능: 공공 API 연동, 혜택 검색, 카테고리별 조회, 회원가입 및 로그인
- 개발 방향: 기본 기능 우선 구현 후 추가 기능 확장

## 팀원 1 — 이용희

### 담당 업무
**프론트엔드 및 메인 화면 / 배포**

- React 기반 프론트엔드 개발
- 메인 페이지 및 혜택 목록 화면 구현
- 혜택 카드와 공통 UI 컴포넌트 개발
- 백엔드 API와 화면 연동
- 프론트엔드 빌드 및 배포
- 배포 환경에서 발생하는 프론트엔드 오류 수정

### 주요 산출물
- 메인 페이지
- 혜택 목록 및 카테고리 화면
- 프론트엔드 API 연결 코드
- 프론트엔드 배포 환경

## 팀원 2 — 이주찬

### 담당 업무
**외부 API 연동 및 데이터 처리**

- 공공데이터포털 지자체 복지서비스 OpenAPI 조사
- 외부 API 요청 및 응답 처리
- XML 응답 파싱 및 JSON 변환
- 혜택 목록 및 상세 데이터 처리
- 외부 API 오류와 타임아웃 처리
- 공통 데이터 구조 설계 지원

### 주요 산출물
- 외부 API 연동 모듈
- XML 파싱 및 데이터 변환 코드
- 혜택 데이터 처리 로직
- 외부 API 테스트 결과

## 팀원 3 — 김동영

### 담당 업무
**검색·필터 및 데이터베이스 / 통합**

- 키워드 검색 기능 구현
- 카테고리별 필터링 기능 구현
- SQLite 및 SQLAlchemy 기반 데이터베이스 설계
- 사용자 및 혜택 데이터 모델 구현
- 백엔드 기능 통합 및 API 연결 구조 관리
- 프론트엔드·백엔드 통합 테스트 지원
- 팀원 간 API 명세 및 데이터 구조 조율

### 주요 산출물
- 검색 및 필터링 API
- 데이터베이스 모델 및 연결 코드
- 백엔드 기능 통합 결과
- 통합 테스트 결과 및 수정 내역

## 팀원 4 — 이동화

### 담당 업무
**웹 디자인 / 회원 기능·배포 / 테스트**

- 웹 서비스의 전체 UI·UX 디자인
- 색상, 레이아웃, 타이포그래피 및 공통 디자인 규칙 정의
- 회원가입 및 로그인 기능 구현
- 비밀번호 해시 처리 및 인증 기능 개발
- 백엔드와 회원 화면 연동
- 배포 과정 지원 및 배포 환경 점검
- 주요 기능 테스트 및 오류 재현

### 주요 산출물
- 웹 디자인 가이드
- 로그인 및 회원가입 화면
- 회원 인증 기능
- 기능 테스트 결과 및 오류 목록

## 공통 협업 규칙

- 모든 팀원은 Git과 GitHub를 사용합니다.
- 개발 전에 API 명세와 데이터 구조를 공유합니다.
- 기능별 브랜치에서 개발하고 코드 리뷰 후 통합합니다.
- API 인증키, 비밀키 및 개인정보를 저장소에 커밋하지 않습니다.
- 담당 기능의 개발 완료 후 다른 팀원의 기능과 연동 테스트를 진행합니다.
- 주요 기능과 배포 상태는 팀원 전체가 확인할 수 있도록 공유합니다.

## 개발 우선순위

1. 개발 환경 및 공통 프로젝트 구조 구성
2. 외부 API 연동 및 데이터 처리
3. 메인 화면과 혜택 목록 출력
4. 검색·필터 및 데이터베이스 구현
5. 회원가입·로그인 구현
6. 프론트엔드·백엔드 통합
7. 배포 및 최종 테스트
8. 일정에 여유가 있을 경우 확장 기능 개발
